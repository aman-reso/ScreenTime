# ScreenTime App - Complete Feature List for Advertising

## 📱 App Overview
**ScreenTime** is a comprehensive digital wellness and productivity app that helps users monitor, control, and optimize their smartphone usage. The app provides detailed insights, app management tools, privacy controls, and gamification features to promote healthier digital habits.

---

## 🎯 Main Features

### 1. 📊 **Screen Time Tracking & Analytics**
- **Daily Screen Time Monitoring**
  - Real-time tracking of daily device usage
  - Hourly breakdown of screen time
  - Daily goal setting and tracking
  - Percentage change indicators (vs previous day)

- **Weekly Statistics**
  - Interactive bar charts (horizontal/vertical orientation)
  - 7-day usage trends
  - Day-by-day comparison
  - Network usage tracking per day
  - Notification count tracking

- **Yearly Usage Stats**
  - Annual screen time summary
  - Customizable color themes
  - Visual usage cards
  - Year-over-year comparison

- **App-Wise Usage**
  - Individual app usage tracking
  - Time spent per app
  - App launch count
  - Category-based grouping
  - Detailed app usage history

---

### 2. 🔒 **App Lock & Security**
- **App Locking**
  - Lock any app with PIN or Pattern
  - Secure app protection
  - Temporary unlock with grace period
  - Auto-lock on app launch
  - Background service monitoring

- **App Time Limits**
  - Set daily time limits per app (hours/minutes)
  - Custom time picker (scrollable hours & minutes)
  - Automatic blocking when limit reached
  - Visual time limit exceeded screen

- **App Launch Limits**
  - Set maximum launches per day (1, 2, 3, etc.)
  - Launch count tracking
  - Automatic blocking after limit exceeded
  - Daily reset functionality

- **Lock Screen Features**
  - PIN entry (4-digit)
  - Pattern lock (9-dot pattern)
  - Secure overlay protection
  - Auto-close blocked apps
